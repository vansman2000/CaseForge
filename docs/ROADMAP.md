# CaseForge Roadmap

## Vision

CaseForge is a desktop application for organizing evidence, preparing litigation, and generating professional case binders.

---

## Current Status

### Completed

- Project creation
- Evidence import
- Automatic file organization
- Image preview
- Properties panel
- Evidence model
- Repository layer
- SQLite database
- Persistent evidence storage
